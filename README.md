# NullNote 📝

> A minimalist, privacy-focused note-taking web and desktop application designed for frictionless capture and high-performance editing.

---

## 🚀 Key Features

- **Web & Native Desktop:** Use directly in browser or install standalone binaries.
- **Local-First & Private:** Data remains under your control with zero unnecessary network overhead.
- **Markdown Native:** Live preview and syntax highlighting for GFM.
- **Keyboard-Driven:** Rapid navigation, quick capture, and seamless search shortcuts.

---

## 💻 Getting Started / Installation

### 🌐 Web App (No installation needed)
Access the live version instantly at:  
👉 **[nullnote.dxvil.com](https://nullnote.dxvil.com)**

---

### 📦 Desktop Application (Pre-built Binaries)

1. Navigate to the **[Releases Page](https://github.com/automataevox/nullnote/releases)**.
2. Download the latest binary for your operating system (Linux, macOS, or Windows).
3. Run or install the binary to launch the standalone desktop app.

---

## 🛠️ Building from Source

For development or custom builds:

```bash
# Clone the repository
git clone https://github.com/automataevox/nullnote.git
cd nullnote

# Install dependencies and run
bun i
bun run dev

# custom build
./electron/build.sh linux         # linux, win, mac options
# compiled binary you find at ./electron-release/
```
